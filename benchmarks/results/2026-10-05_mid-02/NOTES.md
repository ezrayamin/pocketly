# Session 2026-10-05_mid-02

Context for the raw files in this folder. Raw files are never edited; `summary.md` and
`summary.csv` are generated by `benchmarks/scripts/collect.ts`.

## Code
- Tag **`bench/2026-10-05_mid-02`** is the commit with these results. Its app code is the same
  as at tag `bench/2026-10-05_mid-01` (slice 4: SQLite storage, History, `androidx.collection`
  fix); the in-app harness was committed after this session and isn't in these builds.
- `bm-01/run.log` is the runner's raw console output.
- Release builds, R8 on, Hermes, split per ABI, debug-key signed.

## BM-08 (size)
- `bm-08-size.json`: per-ABI split APKs (`apk-size.ts`). `bm-08-download/`: bundletool 1.18.3
  `get-size total --dimensions=ABI`.
- Two effects mix in the total: the KMP architecture, and the storage choice (op-sqlite bundles
  SQLite into jsCore; kmpCore uses the platform's). `summary.md` splits them at APK level.
  The download-level split in the performance report is an estimate (`gzip -9` per library).

## Device
- `device.json`: refresh rate **setting pinned at 120 Hz** (`system.peak_refresh_rate=120.0`,
  `global.vivo_screen_refresh_rate_mode=120`). **The ROM still runs Pocketly at 60 Hz**, idle
  and while scrolling, in both builds (the launcher runs at 120 Hz). The app requests no rate;
  vivo's per-window policy (`dvrrWindowFrameRateHint`) sets it. So frame rates in this and
  earlier sessions are out of 60, not 120.
- Phone restarted before the session; airplane mode on, Wi-Fi and Bluetooth off, animations 1x,
  on the charger.

## BM-01 (startup)
- `bm-01-startup.sh`, 2 warm-up + 20 measured per build, alternating, `verify` compilation,
  all 40 measured launches COLD. Battery 32.2–33.0 °C (per launch in each raw file).
- Fresh install before the session; the first launch after it seeded and synced the replica
  (a warm-up round). Measured launches read the cached replica, then sync a zero-entry delta.
- Two earlier attempts were cut short when adb stopped answering while the phone stayed
  attached over USB (an install hung; a launch returned nothing); `adb reconnect` recovers it.
  The script now checks adb before each launch, retries installs with a 120 s timeout, and
  relaunches once when `am start` returns no output. In the completed run, the kmpCore install
  needed 3 attempts; no launch needed a relaunch.
